\section{Введение}
Теорема Пифагора - одна из ванжнейших теорем евклидовой геометрии. Она находит
применение в самых разных областях:
\begin{itemize}
    \item геометрия и тригонометрия
    \item физика
    \item инженерные расчеты
    \item компьютерная графика
\end{itemize}
\section{Формулировка теоремы}
\textbf{Слова:}
В прямоугольном треугольнике квадрат гипотенузы равен сумме квадратов катетов.
\\
\begin{center}
    \begin{equation}
        c^2 = a^2+b^2
    \end{equation}
    Как видно из формулы 1, значение двух сторон позволяет найти третье.
\end{center}
\section{Доказательство (набросок)}
Одно из доказательств основывается на площади квадрата, составленного
из четырёх одинаковых прямоугольных треугольников и малого квадрата
в центре. Раскладывая площадь двумя способами, получаем $c^2 = a^2+b^2$.
\section{Примеры расчёта}

\subsection*{Пример 1}

\[
a = 3, b = 4
\]

\[
c = \sqrt{a^2 + b^2}
  = \sqrt{9 + 16}
  = 5
\]

\subsection*{Пример 2}

\begin{enumerate}
    \item Дано: a = 5, b = 12
    \item Решение:
\end{enumerate}

\[
c = \sqrt{5^2 + 12^2}
  = \sqrt{25 + 144}
  = 13
\]
